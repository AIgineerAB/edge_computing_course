- power rails - + and - full length
- tie points  - connected in columns of 5 
- center gap - separates two sides


With the breadboard we can experiment and learn raspberry pi or other microcontroller very quickly avoiding the need to solder the components. This makes it easy to change the design and try things out without having a permanent finished design. After experimentation is done on the breadboard and if you want a more permanent solution that you are happy with, you can solder those components together. 

> [!NOTE] 
> we won't do any soldering in this course.
